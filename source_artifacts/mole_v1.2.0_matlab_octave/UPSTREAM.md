# Upstream MOLE source snapshot

These files are verbatim snapshots from **MOLE v1.2.0**, Git commit `15de866`,
retrieved from `csrc-sdsu/mole` on 2026-08-20.

The upstream README states that MOLE's mathematics is based on Corbino and
Castillo (2020), while Castillo and Grone (2003) are cited as earlier similar
matrix-analysis operators. The coefficient tables in `divNonPeriodic.m` and
`gradNonPeriodic.m` are the reference arrays translated by the discovery
notebook.
