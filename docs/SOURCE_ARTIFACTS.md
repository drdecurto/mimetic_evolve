## Pinned MOLE reference implementation

The release includes a source snapshot of the MATLAB/Octave reference implementation used to audit the embedded order-2, 4, 6, and 8 arrays:

```text
source_artifacts/mole_v1.2.0_matlab_octave/
```

Upstream tag: `v1.2.0`  
Upstream commit: `15de866`

The directory contains `divNonPeriodic.m`, `gradNonPeriodic.m`, `weightsP.m`, `weightsQ.m`, the upstream README, and a provenance note. The independent source-block comparison is generated by `scripts/audit_mole_reference_attribution.py`.

The upstream MOLE project states that its mathematics is based on Corbino and Castillo (2020) and cites Castillo and Grone (2003) as an earlier related matrix-analysis family. Accordingly, authoritative analysis and derived outputs use the label `MOLE/Corbino--Castillo`; immutable notebook labels are retained only as historical provenance.
