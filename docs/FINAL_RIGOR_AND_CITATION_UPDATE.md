# Final rigor and citation update

This update addresses four final review points in this release.

1. **Contrapositive scope.** The non-real reference modes unconditionally exclude an SPD self-adjoint similarity of the fixed Dirichlet block. Exclusion of the compiler's stricter endpoint-supported identity is now stated only together with positive-definite weights and a scalar norm that respects Dirichlet elimination, matching the hypotheses of the proposition.
2. **Figure citations.** The reference-spectrum sentence now cites Figure 1, and the mesh-refinement paragraph now cites Figure 4. Every figure is cited in the analysis text.
3. **Sign-flip randomization test.** The Methods and Results sections now state that the test enumerates all `2^10` sign assignments of the observed seed-level differences while retaining their magnitudes. Raw p-values are therefore multiples of `1/1024`; the two-sided minimum is `2/1024`. This distinguishes the procedure from a binomial sign test.
4. **Bibliography cleanup.** An uncited Bauer--Fike entry was removed from the reference list used for the write-up of these results.

No numerical result, exact certificate, operator array, or search outcome changed.
